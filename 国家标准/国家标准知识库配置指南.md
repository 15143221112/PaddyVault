## 0. 定位与总体策略

### 0.1 这个库是什么
收录稻谷/大米/种子/加工/气象等级等**国家标准原文**，用于回答"标准怎么规定""指标限值是多少""怎么检验判定"等事实型、条款型问题。

### 0.2 设计原则（专家结论）
1. **标准类长文档 ≠ 短知识点**：必须用**大分块 + 父子分块**，保住条款上下文，不能按 512 字硬切。
2. **数值必须逐字引用**：标准答案的正确性 = 检索召回准 + 生成不编造，二者靠分块与提示词共同保证。
3. **权威文件优先于整理稿**：国家标准 PDF 单独建库，不与 md 知识库混装，避免向量互相干扰。
4. **混合检索 + 知识图谱**：BM25 命中标准号/条款词，向量命中语义，图谱打通标准间的引用关系。

## 2. 解析引擎（索引与解析 → 解析引擎）

| 文件类型 | 推荐引擎 | 理由 |
|---|---|---|
| PDF `.pdf` | **anydoc（默认）** | 内置统一解析器，带 OCR 与表格识别，处理扫描件/图文混排最稳 |
| Word `.docx/.doc` | anydoc（默认） | — |
| 演示文稿 `.pptx/.ppt` | anydoc（默认） | — |
| 电子书 `.epub` | anydoc（默认） | — |
| Markdown `.md` | 内置（默认） | — |
| CSV / Excel | Simple / 内置（默认） | 标准指标表如转成表格再导入 |

### MinerU 增强（推荐流程）
WeKnora 内置引擎**不含 MinerU**。对于扫描版国标（如 7MB 的 GBT1354），推荐：
1. 用 MinerU 在线解析把 PDF 转成**结构化 Markdown**（表格、指标、条款层级保留最好）；
2. 再把 Markdown 导入 WeKnora（走"内置"引擎，质量最高）。

**对比测试**：拿 `GBT1354-2018-大米.pdf`（7MB）分别走「anydoc 直解析」和「MinerU 转 md 再导入」，对比整精米率分级表、水分限量、检验方法的还原完整度，谁好全库统一用谁。

## 4. 分块设置（索引与解析 → 分块设置）

**核心：长条款不能切碎。** 国家标准每条条款 / 每张指标表应作为一个完整上下文，而不是 512 字硬切。

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 分块策略 | `自动`（或结构感知） | 按标题/段落结构自适应切分 |
| 分隔符 | 默认：双换行 → 单换行 → 中文句号 → 感叹号 → 问号 → 分号 | 段落优先，保住条款完整性 |
| 父子分块 | ✅ **开启** | 长文档（标准 >10 页）必开 |
| 父块大小 | `4096` 字符 | 返回给 LLM 的上下文块，保住整条条款 |
| 子块大小 | `384` 字符 | 用于向量匹配，精准命中"整精米率""垩白度"等指标词 |

> 专家提示：子块 384 负责"找得准"，父块 4096 负责"答得全"。检索先拿子块精准匹配条款，再取父块喂给 LLM，避免指标数值因切碎而丢失上下文。

## 5. 知识图谱（索引与解析 → 知识图谱）

**建议开启。** 国标之间存在"引用/代替/适用于"关系，图谱可支持跨标准问答（如"GBT1354 与 GB1350 的关系""冷害评估依据哪个标准"）。

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 启用实体关系提取 | ✅ 开启 | 自动抽取实体与关系 |
| 额外提取要求 | 见下方提示词 | 限定水稻/标准领域实体与关系 |
| 关系类型 | 见下方列表 | 逗号分隔 |
| 示例文本 | 见下方文本 | 先测试抽取效果再保存 |

**额外提取要求提示词（粘贴，≤4000 字）：**

> 领域为稻米国家标准与农业气象。重点提取实体：国家标准编号与名称（GBT1354-2018 大米、GB1350-2025 稻谷、GBT17891-2017 优质稻谷、GBT20569-2006 稻谷储存品质判定、GBT37744 水稻热害气象等级、GBT34967 北方水稻低温冷害等级、NYT2156 水稻主要病害防治、NYT593 食用稻品种品质等）、适用对象（稻谷/大米/种子/品质/加工/气象等级）、关键指标（整精米率、垩白度、垩白粒率、直链淀粉、胶稠度、蛋白质、水分、杂质率、不完善粒、出糙率、容重）、分级等级（特等/一等/二等/三等、优等/合格）、发布与实施日期、代替标准。关系类型限定为：适用于、属于、规定、引用、代替、发布、实施、符合、达到、检验、判定。只抽取文本明确出现的关系，禁止臆造；保留分级限量的数值属性。

**关系类型（粘贴，逗号分隔）：**

```
适用于,属于,规定,引用,代替,发布,实施,符合,达到,检验,判定,来源于
```

**示例文本（测试用，替换默认随机文本）：**

> GBT1354-2018 规定了大米的等级划分，一等大米整精米率不低于 55%，垩白度不大于 3.0%；该标准代替 GBT1354-2008，适用于商品大米的生产与检验；GB1350-2025 适用于稻谷，规定水分含量为 13.5%~14.5%；GBT17891-2017 适用于优质稻谷品质判定，引用 GBT1354 的相关检验方法。

## 10. 常见问题与红线

| 问题 | 处理 |
|---|---|
| 扫描版 PDF 解析乱码/表格丢 | 切 MinerU 转 md 再导入 |
| 答案数值对不上 | 检查父子分块是否开启；确认 Wiki 提示词禁止编造 |
| 指标词搜不到 | 调低检索阈值到 0.5；确认子块 384 生效 |
| 引用来源不对 | 重新解析该文档，清理旧索引 |
| 解析耗时过长 | 关知识图谱或降低生成问题数量 |
| 多模态显存不足 | 关 VLLM，仅靠 OCR 文本解析 |

**红线（专家要求）：** 标准数值、分级表、限量指标必须逐字引用原文，任何生成环节不得编造或推断数值。
